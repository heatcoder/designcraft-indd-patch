# Heatcoder — toolbar update

Installed and tested on this Mac as Heatcoder 0.8.0-heatcoder.7. Other-platform installer checks run separately.

- **Free Transform (E):** select an object, drag a handle to scale its frame and contents, drag inside to move, or just outside a corner to rotate. Command+Option on Mac / Ctrl+Alt elsewhere starts a shear drag. Undo reverses a completed gesture.
- **Measure (K):** drag between two points to see distance, horizontal and vertical offsets, and angle. Hold Shift for 45-degree increments. Escape clears the measurement.
- **Note:** click in a text frame, enter the note and optional author, then confirm. Notes are saved with the document and do not print. Use the Notes panel to edit or delete them.
- **Color Theme (Shift+I):** click a placed image or coloured object. Review up to five image colours (or the object's fill/stroke), apply a colour to the selection, or save the palette as a swatch group.
- **Vertical Type on a Path:** open the Type tool group, choose the vertical path tool, click an empty path at the desired starting point, then type. Existing path text remains editable.
- **Apply Gradient:** select an object, bring Fill to the front, then use the gradient button below the fill/stroke controls.

Right-click a tool group to reveal its other tools. Color Theme samples the whole placed image, not only its crop. Gradient application here is for object fills. These additions do not claim complete feature parity with InDesign.
