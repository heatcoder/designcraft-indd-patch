A free enhancement for DesignCraft, adding INDD opening and Malayalam typing. Built on open-source projects; credits and licences are included.

2. Issues and solutions

INDD file will not open

Solution: Launch DesignCraft, choose File → Open and select the .indd or .indt file. The importer works locally inside the app. Save your work as .designcraft or export .idml.

Malayalam has square boxes and extra spaces

Cause addressed: Some legacy FML fonts lack glyphs for nonbreaking separators and curly quotation marks. The missing glyphs appear as boxes and add unwanted width.

Actual app renders of a diagnostic glyph sample, not a document excerpt. Both use the same text, font and size.

Solution: The patch uses the font’s existing separator and quotation-mark glyphs for display. It preserves your original document text and existing “ണ്ട” conjuncts. Install your matching licensed FML fonts; they are not included.

This addresses those specific missing characters. It does not fix every spacing issue, convert old FML text to Unicode, or guarantee the same page breaks as the original document.

3. Type Malayalam inside DesignCraft

The new option is Window → Malayalam (Heatcoder).

  1. Open Window → Malayalam (Heatcoder).
  2. Choose Manglish or InScript. Keep your system keyboard set to English.
  3. Select the Type tool (T) and click inside a text frame. Type Malayalam directly on the page.
  4. Select existing text to replace it. In Manglish, Space finishes the word and Backspace revises the current word. Undo and Redo work as usual.
  5. Choose Off, or close the panel, to return to normal typing. Paste retains its usual behavior.

There is no separate text-entry dialog or Insert button.

Manglish is case-sensitive: T, D, N, L and R have distinct mappings. It follows fixed spellings rather than predictive suggestions. InScript uses Malayalam keyboard positions.

Noto Sans Malayalam is bundled for new Unicode text. Typing works offline; Typeit! is not required. Existing legacy FML text stays unchanged.

4. Install and open

Close DesignCraft first. The installer updates the existing app and saves a backup.

Choose your operating system above for installation steps.

  1. Open DesignCraft, then choose File → Open.
  2. Select your INDD file and check the fonts, pictures and page layout.
  3. Save as .designcraft or export .idml. Keep your original file.
