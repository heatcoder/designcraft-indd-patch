Release notes

MalayalamPatch by Heatcoder · Free enhancement for DesignCraft · Preview build · 17 October 2026

What’s included

  • Open INDD and INDT files directly in DesignCraft.
  • Display fixes for specific missing separator and quotation-mark glyphs in legacy FML fonts.
  • Window → Malayalam (Heatcoder): Manglish and InScript typing directly on the page.

Distribution review

Public downloads are paused. Dependency notices, source provenance and final installers are still under review. Open-source declarations and generated code do not automatically establish redistribution rights.

INDD is read locally and converted to IDML in memory. This path does not require InDesign, modify Adobe software or unlock an Adobe licence. Separately licensed fonts and PDF resources, including some Adobe-authored open-source material, require accompanying notices.

Read the full distribution audit

Installer verification

These installers are not yet signed with a verified publisher certificate. The Mac app has an ad-hoc signature and is not Apple-notarized. Your computer may show a security warning. The installer does not disable security settings.

Document requirements

  • Keep original fonts and linked images available, including Links and Document Fonts folders where supplied.
  • Missing fonts can change line breaks. Missing images may use low-resolution previews; relink originals before printing.
  • Review fonts, images, text flow and every page before production use. Some InDesign formatting may differ.
  • Save as .designcraft or export .idml. INDD export is not supported. Keep your original INDD file.
  • For legacy FML text, select the whole word before replacing it with new Unicode Malayalam.
  • Desktop builds only: macOS, Windows and Linux. No Android or iOS version.

Updating DesignCraft

Close DesignCraft before installing. Native installers update the existing app and save a rollback copy. Documents and settings are preserved. Portable archives do not perform an automatic upgrade.

Uninstall

macOS: remove the app. Windows: use Installed apps. Debian/Ubuntu: remove the designcraft package.
